# CloudOTP GIF Assets

Use this folder for short demo GIFs used in the README, GitHub Releases, or community posts.

## Suggested GIFs

- `add-account.gif`: add a demo account.
- `copy-code.gif`: copy a TOTP code from the Windows app.
- `export-qr.gif`: export a demo account as a QR code.

## Recording Rules

- Use fake/demo accounts only.
- Keep each GIF short, ideally under 10 seconds.
- Avoid showing real OTP secrets, personal emails, real recovery codes, or real export QR codes.
- Crop to the app window when possible.
